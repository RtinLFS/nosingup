## 🤖 AI Chatbots

Chat with AI models **without creating an account**:

| Website | Description |
|---------|-------------|
| [Duck.ai](https://duck.ai) | 🏆 DuckDuckGo's anonymous AI chat — access GPT-4o mini, Claude Haiku, Llama & Mistral with no account. Chats are not stored. The gold standard of no-signup AI. |
| [Dolphin Chat](https://chat.dphn.ai/) | Dolphin chat provides Dolphin X1 Nano 8B - uncensored (trained on Llama3.1 8B) for free and without sign-up |

| [Venice](https://venice.ai) | Privacy-focused AI chat & image generation running open-source models. No account required for basic use. |
| [Perplexity](https://www.perplexity.ai) | AI answer engine with sources. Basic search/chat works anonymously; account only needed for Pro & history. |
| [Phind](https://www.phind.com) | AI search engine built for developers. Usable without an account. |
| [Vercel AI Playground](https://sdk.vercel.ai) | Try many LLMs side-by-side with small free credits. No sign-up. |
| [ChatGPT](https://chatgpt.com) | Offers a no-login mode in many regions (may occasionally prompt to sign in). |
| [Microsoft Copilot](https://copilot.microsoft.com) | Guest mode available; Microsoft increasingly nudges guests toward sign-in. |
| [iAsk](https://iask.ai) | AI search engine — ask questions, get instant answers. No account. |
| [DeepAI Chat](https://deepai.org/chat) | Simple AI chat plus a huge toolbox of AI utilities. Free & limited without account. |

## 🤝 Contributing

Found a great no-signup website? Policies changed? Contributions are welcome!

1. The site must be usable **without any account** (guest/nickname-only is OK for games).
2. Add it to the right category in a table row: `\| [Name](url) \| Short description \|`
3. Open a pull request. ✨
